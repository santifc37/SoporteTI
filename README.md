# SoporteTI

Sistema web para la gestión de solicitudes de soporte tecnológico.

## Descripción

SoporteTI es una plataforma web que permite registrar, administrar y realizar seguimiento a solicitudes de soporte técnico. Facilita la comunicación entre solicitantes, técnicos y coordinadores, conservando el historial de atención de cada solicitud.

## Objetivo

Desarrollar una aplicación web que centralice la gestión de solicitudes de soporte tecnológico, permita controlar su atención y facilite la supervisión de los procesos de soporte.

## Roles del sistema

- **Solicitante:** registra solicitudes, consulta su estado y se comunica con el personal de soporte.
- **Técnico:** atiende las solicitudes asignadas, registra intervenciones y documenta soluciones.
- **Coordinador:** administra usuarios, evalúa solicitudes, asigna técnicos y supervisa el funcionamiento del sistema.

## Tecnologías

- **Backend:** Python y FastAPI.
- **Frontend:** React y TypeScript.
- **Base de datos:** PostgreSQL mediante Supabase.
- **Almacenamiento:** Supabase Storage.
- **Control de versiones:** Git y GitHub.
